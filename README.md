## Инструкция по запуску

1. Установить зависимости
   pip install -r requirements.txt
2. Обучить модель
   python main.py
3. Применить модель к Владимирской области
   python predict_vladimir.py

## ЦЕЛЬ ПРОЕКТА

Разработка модели машинного обучения для оценки заселенности зданий на основе данных OpenStreetMap (OSM) и применение модели к Владимирской области.

## Данные для обучения модели:

- Пермский край: Данные по населению с координатами и адресами
- Свердловская область: Данные по населению с координатами и адресами
- Общий размер: 48,885 записей

## Данные для прогнозирования:

- Запрос OSM
- Владимирская область: Данные получены через Overpass API
- Количество объектов: 56,455 записей

# Стандартизация колонок и адресов:

- Разработаны функции для парсинга различных форматов адресов
- Извлечение номера дома, типа населенного пункта
- Классификация типов зданий (apartments, house, residential, dormitory)

# Подготовка признаков

Создание признаков для модели:

- Географические: координаты, сумма/разность координат
- Региональные: кодирование региона
- Адресные: тип населенного пункта
- Номер дома: четность, категория (small, medium, large, very_large)
- Пространственная плотность: плотность зданий в ячейке
- Характеристики здания: площадь, количество этажей
